## 1. 为什么需要细胞级定量分析

乳腺癌免疫组化(IHC)判读的核心，不在于整张图像，而在于肿瘤区域内的单个细胞表达状态。ER、PR、HER2 和 Ki-67 等标志物的临床评分均依赖对肿瘤细胞阳性比例与染色强度的精确统计，而非对非肿瘤细胞或全图的整体估计。Liu 等提出在乳腺癌 IHC 全切片图像中自动分割侵袭性癌区域(invasive carcinoma region)，并基于该区域实现 Ki-67 定量评分系统，该自动评分与病理医生评分高度一致，证明了定位肿瘤区域是量化分析的必要前提[[1]](#ref1)。由于肿瘤组织内标志物表达具有显著空间异质性，且评分阈值对治疗决策高度敏感，人工判读不仅存在观察者差异，也难以全面量化。

具体而言，ER/PR 的 Allred 评分系统要求同时评估阳性细胞百分比(PS，0-5分)和染色强度(IS，0-3分)，总分≥3分判为阳性可接受内分泌治疗，<3分判为阴性通常需要化疗。在边界情况下(如总分2分)，精确的细胞计数和强度评估至关重要。HER2 判读需要区分 0、1+、2+、3+ 四个等级，IHC 3+ 可直接使用靶向治疗，IHC 2+ 需 FISH 验证，IHC 0/1+ 通常不使用靶向治疗。在 HER2 低表达(1+)成为治疗靶点的今天，准确区分 0 和 1+ 具有重要的临床意义。研究显示，在当地实验室评估为 HER2 0 的乳腺癌中，有高达 85% 的病例经中心实验室重新评估后改为 HER2 1+ 或 HER2 2+，这种差异在 HER2 低表达的区分中尤为明显。Ki-67 计数用于区分 Luminal A(Ki-67<20%)和 Luminal B(Ki-67≥20%)，直接影响是否需要化疗。在 20% 阈值附近，几个百分点的差异就可能改变治疗方案。

然而，人工判读存在显著的观察者差异和实验室间变异性。大规模人群研究显示，Ki-67 指数在不同病理实验室间存在显著差异(inter-lab variability)，即使在同一实验室内，不同年份也存在明显波动[[2]](#ref2)。这种变异性不仅影响诊断准确性，也影响多中心研究和临床试验的一致性。

因此，癌区识别 + 细胞级定量分析是乳腺癌 IHC 判读客观化、标准化与可重复的前提：只有先定位肿瘤区域，再对肿瘤细胞进行阳性判定和染色强度统计，才能得到临床可用的评分结果，并指导分子分型及治疗方案选择。标准化的细胞级定量分析可以扫描整个切片，识别所有肿瘤细胞，提供更全面、更客观的评估，支持大规模研究和多中心合作。当前 AI 正用于自动化 ER、PR、HER2 等 IHC 标志物的评分，自动方法的目标包括提升准确性、减少人工主观性，并提升 IHC 判读一致性与效率[[3]](#ref3)，这也进一步证明了标准化细胞级定量分析的价值。

## 2. IHC 基本原理与技术流程

免疫组化技术基于抗原-抗体特异性结合的原理。当组织切片中的目标蛋白(抗原)与特异性抗体结合后，通过标记系统(如酶标记)进行信号放大，最终通过显色反应在显微镜下可见。IHC的核心机制包括三个步骤：首先是一抗(第一抗体)特异性识别组织中的目标抗原蛋白；其次是二抗(第二抗体)与一抗结合，二抗通常标记有酶(如辣根过氧化物酶HRP)或生物素等放大元件，实现信号放大；最后是标记的酶催化底物(如DAB)产生不溶性有色沉淀，沉积在抗原所在位置，形成可见的染色信号。

DAB(3,3'-二氨基联苯胺)是最常用的显色剂。在辣根过氧化物酶(HRP)的催化下，DAB与过氧化氢(H₂O₂)反应，生成棕黄色至棕色的不溶性沉淀产物。该产物沉积在抗原所在位置，形成可见的染色信号。显色时间通常为5-10分钟，需要在显微镜下监测，避免过度显色导致背景染色。

### IHC 标准化技术流程

临床实践中，一套标准的免疫组化(IHC)检测流程涵盖了从样本前处理到信号转化的严苛环节，具体步骤如下：

- **组织固定与切片**：离体组织需立即置于 10% 中性福尔马林中固定 24-48 小时，以平衡抗原保存与细胞形态维持。固定后的样本经脱水、透明、浸蜡后进行石蜡包埋，并使用切片机切取 4-5μm 的超薄切片贴附于载玻片。

- **脱蜡水化与抗原修复**：切片依次通过二甲苯及梯度乙醇进行脱蜡与水化。随后进行关键的抗原修复步骤——通过热诱导(如使用 pH 6.0 柠檬酸或 pH 9.0 EDTA 缓冲液高压加热)或酶消化法(如蛋白酶 K)打开化学交联，暴露被遮蔽的抗原表位，这是确保抗体有效结合的核心前提。

- **封闭与一抗孵育**：使用正常血清或 BSA 封闭组织上的非特异性结合位点，以降低背景噪声。随后滴加特异性一抗，在 4℃ 过夜或 37℃ 环境下孵育 1-2 小时，其浓度需经过预实验优化以确保信号特异性。

- **二抗级联与信号放大**：滴加标记有酶(如辣根过氧化物酶 HRP)的二抗，在 37℃ 孵育 30-60 分钟。通过二抗与一抗的结合，实现分子层面的信号级联放大。

- **显色与复染**：使用 DAB 显色液作为底物，在显微镜下动态监测棕褐色沉淀的生成(通常为 5-10 分钟)。显色完成后，使用苏木精(Hematoxylin)对细胞核进行复染，以便于在镜下观察组织形态结构。

- **脱水封片与判读**：切片经梯度酒精脱水及二甲苯透明后，使用中性树胶封片。最终由病理医师或自动化 AI 系统根据染色强度与阳性细胞比例进行标准化评分。

## 3. 核心生物标志物详解

乳腺癌免疫组织化学(IHC)检测主要关注ER、PR、HER2和Ki-67四个核心生物标志物。上述指标在亚细胞定位、形态学表现、判读方法及临床意义方面存在显著差异，是乳腺癌分子分型及治疗决策的重要依据：

### 3.1 ER/PR(雌激素受体/孕激素受体)

ER/PR是乳腺癌最重要的内分泌治疗预测标志物。其阳性表达提示肿瘤生长依赖雌激素或孕激素信号通路，通常对内分泌治疗具有良好反应。

- **定位**：主要定位于肿瘤细胞核内，IHC 染色呈棕黄色至深棕色核染色，可表现为均匀或颗粒状分布。
- **临床意义**：ER/PR阳性肿瘤通常分化程度较高、生物学行为相对温和，预后较好；ER/PR阴性肿瘤往往侵袭性更强、预后相对较差。

**判读流程**：在ER/PR的实际判读中，病理医生通常首先在低倍镜(×4/×10)下对整张切片进行扫描，以确认可评估区域为浸润性乳腺癌肿瘤组织，并排除正常乳腺导管、炎症细胞、间质成分及其他非肿瘤组织的干扰。同时评估免疫染色的整体质量，包括内对照是否阳性以及是否存在整片染色失败等技术问题，并初步观察ER/PR表达在肿瘤内是否存在空间异质性。在此基础上，切换至高倍镜(×20/×40)，在染色质量良好且具有代表性的浸润性肿瘤区域内，对肿瘤细胞核进行判读与计数，刻意避开坏死区、切片折叠及明显背景脏染区域，从而获得可靠的阳性细胞比例评估结果[[4]](#ref4)[[5]](#ref5)。

### 3.2 HER2(人表皮生长因子受体2)

HER2是乳腺癌分子分型及靶向治疗决策中的关键标志物，其基因扩增或蛋白过表达提示患者可从抗 HER2 靶向治疗(如曲妥珠单抗)中获益。

- **定位**：主要定位于肿瘤细胞膜，IHC染色表现为细胞膜棕黄色至深棕色染色，可呈连续或不连续分布，明显区别于ER/PR的核定位。

- **临床意义**：HER2阳性肿瘤通常具有较高的增殖活性和侵袭性，未经靶向治疗时预后较差，但对抗HER2治疗反应显著；HER2阴性肿瘤则不从此类治疗中获益。

**判读流程**：在HER2的实际判读中，病理医生首先在低倍镜(×4/×10)下整体扫描切片，确认评估对象为浸润性乳腺癌肿瘤组织，排除正常乳腺上皮、导管原位癌(DCIS)及其他非肿瘤成分的影响，并评估免疫染色的整体质量，包括膜染色是否清晰、背景是否干净以及是否存在整片染色失败的情况。同时观察HER2表达是否存在明显的空间异质性。在此基础上，于高倍镜(×20/×40)下，在具有代表性的浸润性肿瘤区域内，重点评估肿瘤细胞膜染色的完整性、连续性及染色强度，结合阳性细胞比例对HER2表达水平进行分级判读，并根据结果决定是否进一步行FISH/ISH检测以明确 HER2基因扩增状态。

| IHC 评分 | 判读要点 | 临床结论 |
|---------|---------|---------|
| 0 | 无膜染色，或 <10% 肿瘤细胞呈不完整、极弱膜染色 | 阴性 |
| 1+ | ≥10% 肿瘤细胞呈**不完整、弱膜染色** | 阴性 |
| 2+ | ≥10% 肿瘤细胞呈**弱至中等、完整或不完整膜染色** | **可疑**(需 FISH) |
| 3+ | ≥10% 肿瘤细胞呈**强、完整、连续的膜染色** | 阳性 |

>注意：HER2 判读以细胞膜染色的结构完整性为核心要素，单纯染色强度或比例并不足以决定分级；此外，HER2 表达的肿瘤内异质性在临床中较为常见。

### 3.3 Ki-67(增殖指数)

Ki-67是反映肿瘤细胞增殖活性的常用指标，用于评估肿瘤生物学行为、复发风险及辅助治疗策略，但本身并非直接治疗靶点。

- **定位**：定位于细胞核内，IHC 染色表现为棕黄色至深棕色核染色，可呈弥漫或灶性分布。

- **临床意义**：Ki-67高表达提示肿瘤细胞增殖活跃，常与高组织学分级及较高复发风险相关；Ki-67低表达则提示肿瘤生长相对缓慢。Ki-67 常与ER/PR/HER2联合用于乳腺癌分子分型(如Luminal A 与Luminal B 的区分)[[6]](#ref6)。

**判读流程**：在Ki-67的实际判读中，病理医生通常首先在低倍镜(×4/×10)下扫描整张切片，确认可评估区域为浸润性肿瘤组织，并排除正常乳腺组织、炎症细胞、坏死区域及技术伪影的干扰，同时观察 Ki-67 在肿瘤内的整体分布特征，识别是否存在增殖活跃的“热点区域(hot spots)”。随后在高倍镜(×20/×40)下，于代表性肿瘤区域(通常优先选择热点区域)对肿瘤细胞核进行计数，仅将出现明确核染色的细胞计入阳性细胞数，从而计算Ki-67阳性细胞所占比例，作为最终的增殖指数[[7]](#ref7)。

>注：Ki-67 判读以细胞核是否阳性为唯一标准，不区分染色强弱，弱阳性与强阳性在统计中等价；Ki-67 评估仅关注阳性细胞比例(Ki-67 index)，不涉及强度分级或结构完整性判断；此外，Ki-67 表达在肿瘤内常呈明显空间异质性，临床判读通常遵循热点优先原则，在增殖最活跃的肿瘤区域进行计数，而非全片随机平均。
